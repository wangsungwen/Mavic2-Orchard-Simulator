# Mavic 2 UE4 選點飛行：果園原型 v1 Windows 可攜版

版本：2026-10-18。此包只控制本機 AirSim 模擬機，不連接 DJI 真機。目標電腦不需安裝 UE4 編輯器、Visual Studio 或 Python。

文件修訂：果園 v1 手冊同步版。完整步驟見 [果園選點飛行操作手冊](docs/UE4選點飛行操作.md)，場景規格見 [山坡柑橘果園原型](docs/山坡柑橘果園原型.md)。這些連結以可攜包根目錄的 README_先讀我.md 為準。

## 第一次使用

1. 完整解壓縮 ZIP 到可寫入的資料夾，例如 `D:\Mavic2Simulator`。不要在 ZIP 內直接執行，也不要放在 Program Files。請保持整包資料夾結構。
2. 需要時執行 `Simulator\Engine\Extras\Redist\en-us\UE4PrereqSetup_x64.exe` 安裝 UE 必要元件；此安裝步驟可能需要管理員權限。本包不自動修改系統設定。
3. 確認使用 64 位元 Windows 與支援 UE4 圖形功能的顯示卡，並安裝對應驅動。不同顯示卡仍需在目標電腦驗收。
4. 可雙擊 `Check-Runtime.cmd`，看到 Runtime OK、AirSim import OK 代表控制程式相依套件可載入。這項檢查不代表 GPU 或模擬飛行已驗收。
5. 關閉其他 UE4／AirSim 場景，雙擊 **Start-Navigation.cmd**。保留控制終端開啟，等待場景左上方 READY。

本版 Start-Navigation.cmd 與 Start-Orchard.cmd 都開啟「第一版山坡柑橘果園」並啟用選點。Start-Blocks.cmd 可開啟原 Blocks 選點場景。切換場景前先關閉目前場景與控制終端。

果園包含 100 × 100 公尺坡地、64 棵幾何果樹及 4 隻會移動的獼猴替身。這是合成原型，並非實測或寫實重建。選點仍沿用起點半徑 20 公尺、1–10 公尺相對高度及 30 公尺寬俯視視野；本次更新沒有擴大飛行範圍，也未加入地形跟隨。俯視畫面只涵蓋起降區附近，並非全果園。首次請選平台附近空地，不要直接穿越果樹或上坡。

首次 Windows 可能顯示 Blocks 防火牆提示。本版只使用 localhost 控制，可選「取消」，不需開放公用網路；請由操作員處理系統提示。若 Windows 顯示其他安全或簽章提示，先依自己的裝置政策檢查來源與雜湊，本包不修改防火牆或安全設定。

## 操作

| 按鍵 | 功能 |
|---|---|
| 左鍵點地面並放開 | 顯示黃色目標與 N/E 座標 |
| 上／下方向鍵 | 高度每次調整 0.5 公尺，範圍 1–10 公尺 |
| Enter | 確認；自動起飛、調高度，再接近目標 |
| X | 取消任務並要求懸停 |

到達 ARRIVED 後可選下一點再確認。飛行途中不接受新的 Enter 任務；先 X 中止才能換目標。速度 0.5 m/s、到點三維容差 0.75 公尺、目標距起點水平半徑上限 20 公尺。高度相對場景啟動後落地的機體位置，不是海拔或點擊表面的淨空。

先在起點附近空地試飛。此版不自動繞障，也不自動降落；碰撞後中止不等於避障。X 和 Ctrl+C 都不是降落。結束時先 X，再關閉 UE4；重新開始請從新場景啟動。

首次果園範例：將高度由 2 公尺按兩次 ↑ 調到 3 公尺，在平台附近選 N/E 約 2/2 公尺的空曠位置，再按 Enter。上坡高度不會自動補償；樹冠、果實、灌木與獼猴替身沒有碰撞，不能據此判斷真實場地可通行。

## 常見問題

- Port 41451 in use：關閉另一個 AirSim／UE4 場景後再啟動，不要重複雙擊。
- 找不到 DLL：先執行包內 UE prerequisites，並確認完整解壓與檔案校驗通過。
- 畫面沒有選點提示：請使用 Start-Navigation.cmd，不要單獨雙擊 Blocks.exe。
- 控制終端出現錯誤：保留完整錯誤與 `Controller\logs\point-*\events.jsonl`。若視窗已關閉，從終端執行 Start-Navigation.cmd 查看結果。
- 碰撞或逾時：結束場景，重新選空曠路線。無需重新安裝。
- UE4 遊戲記錄位於 Simulator 下的 Blocks/Saved/Logs，或 Windows 使用者 LocalAppData 下的 Blocks/Saved/Logs，依執行環境而異。

## 完整性檢查

在本包根目錄開啟 PowerShell：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Verify-Package.ps1
```

顯示 PASS 代表清單內原始檔案符合 SHA-256。修改設定檔後校驗會不一致；執行產生的 logs 不列入清單。

## 功能範圍與來源

`docs/UE4選點飛行操作.md` 已同步為果園版，分開說明可攜包與來源專案。可攜包的 Start-Orchard.cmd 開啟果園選點；來源專案根目錄同名檔案只開一般果園，來源版選點須使用 `point_navigation.py --scene Orchard`。Source 是自訂控制程式與 Blocks 模組修改的參考，不是完整可重建的 UE4/AirSim 原始碼包。

Mavic 模型來源：使用者提供的 GrabCAD「dji-mavic-2-pro-drone-rail-2020-1」與轉換 FBX，經拆分機身／旋翼及 UE4 藍圖修正。模型外觀不等於 DJI 精確動力模型。AirSim 及其許可見 Licenses。UE4 為 Epic Games 軟體，本包只附打包執行需要的檔案。

本版本新增山坡果園原型，同時保留 Blocks 地圖；未建立實測場地、真機定位或戶外 GPS 控制。測試範圍與限制另見包內驗證記錄。
