# 山坡柑橘果園原型

本版為可執行的 UE4.27 / AirSim 合成果園，使用程式生成的地形、基本幾何植被與獼猴替身。不是實測場地重建，也不是寫實動物模型；適合先檢查場景接入、可見性與飛行控制。

## 開啟

在專案根目錄雙擊 `Start-Orchard.cmd`。原本 `Start-Mavic2.cmd` 仍開啟 Blocks。
同時只能啟動一個使用 41451 埠的模擬器；切換前請關閉現有模擬視窗。

```powershell
# 遊玩模式
.\Start-Orchard.cmd
# 開啟編輯器，按 Play 啟動 AirSim
.\Start-Orchard.cmd -Editor
```

地圖：`/Game/Orchard/Maps/Orchard_Hillside`。
保留 MavicSim、BP_Mavic2、既有相機設定與 localhost:41451。
可攜版更新目標為 `dist/Mavic2Simulator-Orchard-v1-20261018.zip`。包內 Start-Orchard.cmd／Start-Navigation.cmd 啟動果園選點，Start-Blocks.cmd 保留原場景；是否已通過打包驗證請見包內驗證記錄。本頁下列 Python／編輯器指令適用來源專案，可攜版依 README_先讀我.md 操作。

## 場景

| 項目 | 內容 |
|---|---|
| 面積 | 100 × 100 公尺 |
| 地形 | 程式三角網格；下坡側平地，上坡約 16% 坡度，加入小幅起伏 |
| 果樹 | 64 棵，8 排，每排中央保留農路；高度約 2.7–3.5 公尺 |
| 植被 | 幾何樹冠、橘色果實、灌木；以實例化網格減少繪圖負擔 |
| 碰撞 | 地形、樹幹、起降平台有碰撞；樹冠、果實、灌木及獼猴替身無碰撞 |
| 獼猴 | 4 隻，Actor 標籤 Macaque_01 至 Macaque_04 |
| 活動 | 固定橢圓路徑，移動 12 秒、停留 4 秒；簡化擺肢與低頭動作 |
| 起降區 | 西側平地，10 × 10 公尺平台 |
| 隨機種子 | 20261018；植被位置可重現 |

獼猴是程式組合的幾何替身，尚無骨架動畫、NavMesh 避障、爬樹或對無人機的反應；既有辨識與追蹤演算法尚未接入。
樹冠能遮擋 RGB 畫面，但碰撞形狀不等於整個樹冠。

## 座標與航線

UE 世界以公分為單位，地圖 X/Y 為 -5000 至 5000。
PlayerStart 設在 UE `(-3600, 0, 45)`；平台頂面為 Z=10 公分。
坡度沿 UE +X 上升，地圖最高處約比平地高 12 公尺。
AirSim 以出生點為局部 NED 原點；既有 OriginGeopoint 25/121 是測試用座標，不是果園的實測定位。

航點高度仍相對起飛點，不能當成離地高度。上坡及樹冠需要額外淨空。
本版只驗證起降區上方的垂直飛行，沒有驗收既有 square.csv 或全果園自主巡航。

## 重建與驗證

關閉 UE4 後，在專案根目錄執行：

```powershell
.\scripts\Build-Orchard.ps1
.\Start-Orchard.cmd
.\.venv\Scripts\python.exe .\scripts\Verify-Orchard.py
# 僅檢查動物位置與畫面，不操作飛行
.\.venv\Scripts\python.exe .\scripts\Verify-Orchard.py --scene-only
```

建置腳本將 `src/ue4/OrchardScene.*` 複製到 Blocks C++ 模組，啟用 ProceduralMeshComponent 與編輯器 Python 工具，編譯後產生地圖及材質。
重建會重設專用果園地圖及其材質；若已手動修改，先另存新地圖再重建。
原 Blocks 地圖及預設啟動地圖不變。

驗證腳本檢查四隻獼猴的移動、擷取 RGB、起飛至 NED Z=-5 公尺、懸停並嘗試降落。
若降落旗標不正確，腳本會回傳非零狀態，不會把接觸地面當作降落成功，也不會強制停槳。
測試後可關閉並重新開啟場景，回到乾淨的初始狀態。

輸出在 `artifacts/orchard/`：

- `scene-build.json`：生成規格。
- `runtime-check.json`：實際運行結果，包含降落限制。
- `scene-check.json`：僅場景驗證結果。
- `orchard-overview.png`：透過 AirSim 相機擷取的全景。
- `orchard-drone-camera.png`：無人機懸停時的相機畫面。
- `macaque-prototype.png`：幾何獼猴替身近景。

本機已有的 SimpleFlight 降落旗標問題見 `docs/Mavic2模型匯入結果.md`：接觸地面、速度歸零後仍可能回報 Flying。果園驗證保留此問題，不更改飛控或放寬驗收標準。

2026-10-18 實際驗證：C++ 編譯及地圖產生成功；4 隻獼猴在 6 秒內各移動約 1.39–2.54 公尺，座標原點校正後符合坡地高度函式。RGB 成功擷取；起飛懸停到 NED Z 約 -4.63 公尺（命令目標 -5 公尺）。降落接觸果園地面且最終速度為 0，但 landed_state 仍為 Flying，完整起降測試因此按設計回傳失敗。沒有進行全果園航線或寫實辨識驗收。
