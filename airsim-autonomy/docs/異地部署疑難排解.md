# 異地部署疑難排解：原始碼包與 DirectX 缺件

文件修訂：2026-10-18。以下記錄來自使用者在另一台 Windows 電腦提供的錯誤照片；尚未收到該電腦安裝完成後成功啟動的驗證結果。

## 1. 找不到 Blocks.uproject

若執行 `airsim-autonomy\Start-Orchard.cmd` 出現 `Missing: ...vendor\AirSim\Unreal\Environments\Blocks\Blocks.uproject`，代表正在執行開發用入口，但沒有完整開發相依檔案。

一般使用者請下載 [完整果園執行包（約 369 MB）](https://github.com/wangsungwen/Mavic2-Orchard-Simulator/releases/download/v1.0.0-orchard/Mavic2Simulator-Orchard-v1-20261018.zip)，不要選 Code → Download ZIP 或 Release 的 Source code ZIP。

完整解壓縮到新的可寫入資料夾，與原始碼分開。正確執行包的根目錄會看到 `Controller`、`Simulator`、`docs`、`Start-Orchard.cmd`、`Start-Blocks.cmd`、`Check-Runtime.cmd`。從這裡執行 `Start-Orchard.cmd`，不用進入 airsim-autonomy，也不用安裝 UE4 編輯器或 Python。

## 2. 缺少四個 DirectX DLL

照片中出現以下缺件：

- `XAPOFX1_5.dll`
- `X3DAudio1_7.dll`
- `D3DCOMPILER_43.dll`
- `XINPUT1_3.dll`

這些屬於舊版 DirectX 元件。已有 DirectX 12 不代表已安裝這些舊版相依元件。Microsoft 的 June 2010 執行元件套件可補充舊版元件，不會將系統 DirectX 版本降級。

### 先安裝包內必要元件

1. 在出錯的電腦關閉模擬器、錯誤視窗及控制終端。
2. 執行包內 `Simulator\Engine\Extras\Redist\en-us\UE4PrereqSetup_x64.exe`。
3. 選 Install；若已安裝且有 Repair 選項，選 Repair。依畫面完成，要求重新啟動時請重開機。
4. 再執行包根目錄的 `Start-Orchard.cmd`。

### 仍缺上述 DLL：安裝 Microsoft DirectX 完整套件

1. 在出錯的電腦下載 [Microsoft 官方 DirectX End-User Runtimes（June 2010）](https://www.microsoft.com/en-us/download/details.aspx?id=8109)。下載檔名為 `directx_Jun2010_redist.exe`。
2. 執行下載檔，指定解壓縮至例如 `C:\DirectX_Jun2010`。
3. **解壓後進入該資料夾，對 `DXSETUP.exe` 按右鍵 → 以系統管理員身分執行，依指示完成安裝。只解壓縮並不等於完成安裝。**
4. 若安裝程式要求重新啟動，先重開機，再執行果園包的 `Start-Orchard.cmd`。

無須重新下載果園包，也不要逐一從第三方 DLL 網站下載、改名或覆蓋系統 DLL。這項處理應在出錯的目標電腦執行，在開發電腦安裝不會修復另一台電腦。

## 3. UE4 did not start AirSim within 90 seconds

若同時出現上述 DLL 錯誤，90 秒逾時是 UE4 未成功啟動造成的後續結果；先修復缺件，不要只增加等待秒數。

若沒有 DLL 錯誤且仍逾時，保留其他錯誤畫面，確認沒有另一個 AirSim 場景占用連線，並執行完整性檢查。在可攜包根目錄開啟 PowerShell：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Verify-Package.ps1
```

`Check-Runtime.cmd` 只檢查控制程式的 Python 相依元件，成功不代表 UE4 的 DirectX 或顯示卡環境已通過。

## 4. 安裝後驗收與失敗回報

成功啟動應出現果園場景及 READY。先在平台附近選 N/E 約 2/2 公尺、高度 3 公尺，再按 Enter；X 中止並要求懸停。此版本只控制模擬機。

若 `DXSETUP.exe` 安裝失敗，請保留安裝程式的錯誤文字或畫面；若安裝成功但場景仍失敗，請提供新的完整錯誤及 `Controller\logs\point-*\events.jsonl`，以及存在時的 `Simulator\Blocks\Saved\Logs` 或 `%LOCALAPPDATA%\Blocks\Saved\Logs` 中的 UE4 記錄。不要只提供 90 秒逾時訊息。
