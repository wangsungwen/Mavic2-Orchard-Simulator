# 果園視角操作更新 v1.1

本次新增全果園瀏覽，保留俯視選點方式。請先點一下 UE4 畫面讓它取得焦點。

| 操作 | 功能 |
|---|---|
| 滑鼠滾輪向上／下 | 放大／縮小視野 |
| W / S | 畫面向上／下平移 |
| A / D | 畫面向左／右平移 |
| 按住滑鼠中鍵拖曳 | 平移視野 |
| F | 顯示整個 100 × 100 m 果園 |
| Home | 回到起飛區，恢復原本 30 m 視野 |
| 左鍵點擊後放開 | 預覽目標座標 |
| 上／下方向鍵 | 調整飛行高度，與相機縮放分開 |
| Enter | 確認飛行 |
| X | 取消飛行並要求懸停 |

相機操作不會發送飛行指令。可平移查看果園任一角落；仍採固定俯視角度，未加入自由旋轉或斜視。

全果園可瀏覽不代表全果園可飛行：目前飛行仍限制在出生點半徑 20 m、高度 1–10 m，超出範圍的目標會被控制器拒絕。高度相對起飛位置，尚未提供地形跟隨或自動避障。首次請在平台附近 N/E 約 2/2 m、高度 3 m 測試。

畫面若出現 Collision，請先 X 中止，重新啟動場景再測試。不要因視角變大而直接穿越樹木或上坡。

舊 v1 執行檔不包含這些按鍵功能，需要更新執行檔；僅下載新手冊不會改變操作功能。
